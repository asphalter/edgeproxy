Client Configuration & Deployment

Deploy the EdgeProxy All-in-One Client container or export raw configurations for private backend hosts.

⬇ Download client.toml
🚀 Single All-in-One Client Quadlet Recommended
Path: /etc/containers/systemd/edgeproxy-client.container

Copy and paste this pre-configured single file into /etc/containers/systemd/edgeproxy-client.container on your backend machine. Podman will automatically pull the container from GHCR, establish the secure Noise tunnel, and poll for upstream changes every 15s.

SERVER URL (SYNC API)
https://auth.{{ settings.get('root_domain', 'edge.mpv.cx') }}
TUNNEL GATEWAY (RATHOLE NOISE)
{{ settings.get('rathole_public_host', settings.get('root_domain', 'edge.mpv.cx')) }}:{{ settings.get('rathole_public_port', '2333') }}
CLIENT SYNC TOKEN
{{ sync_token }} 
[Unit]
Description=EdgeProxy Client (All-in-One)
After=network-online.target
Wants=network-online.target

[Container]
ContainerName=edgeproxy-client
Image=ghcr.io/vvelectron/edgeproxy-client:latest
Network=host
Volume=edgeproxy_client_data.volume:/etc/rathole:z
Environment=SERVER_URL=https://auth.{{ settings.get('root_domain', 'edge.mpv.cx') }}
Environment=SYNC_TOKEN={{ sync_token }}
Environment=INTERVAL=15

[Service]
Restart=always
TimeoutStartSec=300

[Install]
WantedBy=multi-user.target
Quick Launch on Client Host: sudo systemctl daemon-reload && sudo systemctl enable --now edgeproxy-client.service
